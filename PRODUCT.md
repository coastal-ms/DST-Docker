# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Dune Awakening self-hosted server owners and trusted administrators using Linux or Windows WSL.

## Product Purpose

DST Docker provides browser-based server setup, map and resource management, backups, game updates and gameplay administration.

## Operating Context

DST Docker is an independent product, distributed as a standalone Linux shell installer. It runs Docker Engine inside Linux or WSL and opens in the user's browser. Windows users also receive a desktop startup icon and a foreground hosting window. Product releases are independent of the Windows Dune Server Tool application.

## Capabilities and Constraints

Owner and Admin permissions remain authoritative. Operations expose their target, progress, result and recovery action. Memory usage, resource ceilings and swap allowance have separate meanings. Saved settings identify their global or map scope and when they take effect. Player-side INI edits use complete manual instructions.

## Presentation

Keep routine workflows compact, readable and direct. Searchable object lists lead to contextual controls. Preserve drafts and target identity across navigation. Show current observations and clear stale, loading or error states. Advanced tools remain accessible without dominating ordinary server tasks.
