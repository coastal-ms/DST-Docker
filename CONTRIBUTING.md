# Contributing to DST Docker

Discuss bugs and proposed changes in the [community Discord](https://discord.gg/tj2x7cywSC). Maintainers coordinate contributions and release scope there.

Use a focused branch, preserve account permissions and existing data, and update the relevant documentation. Keep PR descriptions to concise bullets explaining what changes for users. See [Docker development](DOCKER-DEVELOPMENT.md) for local setup and artifact builds.

DST Docker has its own product version and releases. Do not change Windows Dune Server Tool version stamps or its updater as part of a Docker change. Credentials, databases, saved worlds and local verification evidence do not belong in the repository.
