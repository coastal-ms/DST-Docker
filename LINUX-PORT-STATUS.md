# Linux hosting

The supported Linux entry point is the DST Docker installer described in [README.md](README.md). It runs the browser application and server services in Docker on native Linux or Windows WSL.

See [Hosting and maintenance](packaging/docker/README.md) for operations and [Development](DOCKER-DEVELOPMENT.md) for source builds. The older desktop/deb scaffolding retained in the source tree is not the DST Docker installation path.
